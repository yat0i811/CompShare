#   pip install -r requirements.txt
#   pip install -r requirements-dev.txt
#   python -m pytest -v
#   ruff check .
#
# 注意: テストは routers.video_router 等を import するため、
# requirements.txt 側の依存（fastapi / boto3 / python-magic など）も併せて必要。
# .env は不要（conftest.py がダミー値を注入する）。
pytest
# asyncio_mode="auto"（設定は pyproject.toml）。async def のテストに毎回マーカーを付けない
pytest-asyncio
# async def 内の同期I/O検知（ASYNCルール群。CLOSE_ISSUES §4-1 の再発防止）
ruff

# Linux/コンテナ（本番）では入らない（sys_platform=="win32"限定）。
python-magic-bin; sys_platform == "win32"
